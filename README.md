# AutoEDA Platform

An automated Exploratory Data Analysis (EDA) web application built using Python, Pandas, Streamlit, Matplotlib, and Seaborn.

## Live Demo

🚀 Streamlit App:
https://dataanalysisss.streamlit.app/

---

## Project Overview

AutoEDA Platform allows users to upload CSV datasets and automatically generate:

* Dataset Preview
* Dataset Shape Analysis
* Missing Value Analysis
* Statistical Summary
* Correlation Heatmap
* Automated Visual Insights

The objective of this project is to simplify the initial data analysis process and provide quick insights without writing repetitive EDA code.

---

## Features

### Dataset Upload

Upload any CSV dataset directly from the browser.

### Dataset Overview

Automatically displays:

* Number of Rows
* Number of Columns
* Dataset Preview

### Missing Value Analysis

Identifies missing values in each column.

### Statistical Summary

Generates descriptive statistics including:

* Mean
* Median
* Standard Deviation
* Min / Max Values
* Quartiles

### Correlation Heatmap

Visualizes relationships between numerical features using a correlation matrix.

## Installation

Clone the repository:

```bash
git clone https://github.com/jayx003/autoeda.git
```

Move into project directory:

```bash
cd autoeda
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
